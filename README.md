## 🚀 Featured Projects

### 🗞️ [MadeNews — AI-Powered Satirical News App](https://github.com/amankumar110/made_news_app)
> *Android · Kotlin · Firebase · GroqCloud AI · GitHub Actions*

Users submit headlines; **Llama 3 via GroqCloud** transforms them into full satirical news stories. A weekly cron auto-generates **25 fresh stories** (5 categories × 5) and pushes them to a public feed.

| Layer | Stack |
|---|---|
| Mobile App | Kotlin · MVVM · Clean Architecture · Jetpack |
| AI Engine | GroqCloud API · Llama 3 · Prompt Engineering |
| Auth & Storage | Firebase Auth · Firestore |
| Backend Automation | Node.js server · Weekly cron job · Vercel |
| CI/CD | GitHub Actions |

🔗 **Live Backend:** [made-news-server.vercel.app](https://made-news-server.vercel.app/)

---

### 💬 [SleekChat — Real-Time Android Chat Application](https://github.com/amankumar110/SleekChat)
> *Android · Java · Firebase · FCM · WorkManager*

A production-grade messaging app with a **tri-state presence engine** (🟢 Online · 🔴 Offline · 🟡 In-Chat), **three-tier message status** (Sent → Seeable → Seen), and offline-resilient message sync via WorkManager. Push notifications delivered even when the app is closed via an FCM + Node.js integration.

| Layer | Stack |
|---|---|
| Mobile App | Java · MVVM · Clean Architecture · Material3 |
| Real-Time Data | Firebase Realtime Database · Firestore |
| Notifications | Firebase Cloud Messaging · Node.js service account |
| Background Sync | WorkManager · Retry policies |
| Auth | Firebase Auth · OTP |

---

### 💱 [MaterialCurrencyExchange — Offline-First Currency Converter](https://github.com/amankumar110/MaterialCurrencyExchange)
> *Android · Kotlin · Retrofit · RoomDB · Hilt · Material You*

Converts **150+ currencies** with hourly-precision live rates. Stale-data detection on launch, pull-to-refresh, and full **RoomDB offline caching** keep the app useful even without a connection. Dynamic **Material You** theming adapts to the user's system palette across light and dark modes.

| Layer | Stack |
|---|---|
| Mobile App | Kotlin · MVVM · Clean Architecture |
| Networking | Retrofit · Gson · Exchange Rate API |
| Offline Storage | RoomDB |
| Dependency Injection | Hilt |
| Theming | Material3 · Dynamic Color · Dark/Light Mode |
